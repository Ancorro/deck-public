One Deck, many hosts

    

      
my-deckdeck

    

    
Every host's sessions show in one tab list, under each host's name, so you stay on one page whichever host you opened. The name at the top is the whole Deck's (Settings → Deck → Name). Each host's LED has its own colour.

Add a script key

    

      
+Add

      →
      
✳ Agent›_ Shell

      →
      
›_Disk

    

    
Turn on Settings → Advanced → Scripts, then tap + on the Scripts bar at the top of the tab column. Describe the key and let an agent write and test the script, or pick Shell and type the command yourself. Tap the new key to run it; its time shows underneath while it runs.

  

  

    
Edit and move keys

    

      
›_hold

      →
      
›_drag

    

    
Hold a key and let go to edit it. Hold, then drag to move it. On a PC, right-click a key for Run, Edit and Delete.

  

  

    
Harness

    

      
Harness

      →
      
CompactResumeRestart

    

    
Left of Esc in the key row (on a PC, in the message box). Compact and Resume type /compact and /resume. Restart relaunches the agent and continues the same conversation, picking up new settings or updates.
